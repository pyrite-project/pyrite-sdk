# PyriteSDK

[Docs](https://pyrite.flowecho.org/docs/sdk)
[Github](https://github.com/pyrite-project/pyrite-sdk)

PyriteSDK 是 PyriteIDE 的插件开发工具包。你可以使用 Python 编写插件代码，通过 SDK 暴露的 API 操控 IDE 的文件系统、编辑器、设备串口、设置项等能力，最终打包为 PYRIX 分发给用户安装。

PyriteSDK is the plugin development toolkit for PyriteIDE. You can write plugin code in Python and utilize the APIs exposed by the SDK to control the file system, editor, device serial port, settings, etc. of the IDE. Finally, you can package it as a PYRIX file and distribute it to users for installation.
