# 配置环境

## 配置开发环境

- [Python](https://www.python.org/)
- [uv](https://docs.astral.sh/uv/) **(不建议使用其他包管理器)**
- [VSCode](https://code.visualstudio.com/)或[PyCharm](https://www.jetbrains.com/zh-cn/pycharm/)等Python编辑器
- [PyriteIDE]() 用于调试插件

## 创建项目

1. 打开项目文件夹
2. 创建虚拟环境
```sh
uv init --python [3.12/3.13/3.14]
uv venv
```
3. 安装依赖
```sh
uv add pyrite-sdk
```
4. 创建插件模板
```sh
uv run pyrsdk create
```

## 打包插件

在创建完模板之后，你可以尝试**打包插件**

运行以下命令打包插件 (`--python-version`默认为`3.14`)

```sh
uv run pyrsdk src -p [Windows/Linux/Darwin] (--python-version [3.12/3.13/3.14])
```
